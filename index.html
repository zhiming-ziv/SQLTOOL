SQLTool

浏览器内运行的数据库工作台 · 界面参照 SQL Server Management Studio

SQLite 3.45.2 (浏览器内 WebAssembly) MySQL / PostgreSQL / SQL Server 本地代理 · 仅监听 127.0.0.1 离线可用（浏览器内引擎）

打开数据库工作台 真实可用

浏览器内跑一个真正的 SQLite 引擎；也可以经本地代理连接 MySQL / PostgreSQL / SQL Server。

  • 执行任意 DDL / DML：建表、索引、视图、触发器、外键
  • 支持 MySQL / PostgreSQL / SQL Server 与服务器端 SQLite 文件
  • 左侧对象树读取真实 schema，双击表名直接看数据
  • 双击单元格直接改库，支持 NULL、类型、约束校验
  • 导入 .db / .sql / CSV，导出 .db / CSV / JSON
  • 数据持久化到浏览器，刷新不丢；随时导出成 .db 文件
  • 显示 EXPLAIN QUERY PLAN 真实执行计划

查看界面演示 纯静态

最初的 SSMS 界面还原稿，使用模拟数据，用于对照视觉细节。

  • 完整的菜单栏 / 工具栏 / 状态栏
  • 对象资源管理器与查询窗口布局
  • 深色与 SSMS 经典浅色两套主题
必须通过本地服务器访问，不能直接双击打开 HTML 文件。
浏览器要求 WebAssembly 与 IndexedDB 运行在 http:// 协议下，file:// 会被安全策略拦截。

启动方式：
· npm install（连接 MySQL / PostgreSQL / SQL Server 前必须执行一次）
· node server.js（Windows 也可双击 start.bat）

启动后访问 http://127.0.0.1:8777/app/index.html

关于远程数据库：浏览器无法打开原始 TCP 连接，因此 MySQL / PostgreSQL / SQL Server 由 server.js 这个只监听 127.0.0.1 的本地代理代为连接。 代理进程的数据库密码不会回传到网页。
浏览器内 SQLite 的数据保存在本机 IndexedDB，不上传任何服务器；
远程数据库的连接由本地代理进程转发，服务不对局域网暴露。
可随时通过「文件 → 导出数据库」把浏览器内的数据带走。
